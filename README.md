# 모두의 회의록

회의를 녹음하면 **말한 사람별로 나눈 텍스트(txt)** 를 만들어 주는 무료 프로그램입니다. (맥 · 윈도우)

- 모든 처리는 내 컴퓨터 안에서만 — 녹음이 서버로 전송되지 않습니다.
- 참석자 수를 정하면 더 정확합니다. "내 목소리 등록"을 하면 내 말은 `[나]`로 표시됩니다.
- 결과: `문서/모두의회의록/` 폴더에 `[00:01:23] [화자1] ...` 형식의 txt. ChatGPT·Claude 등에 넣어 요약·분석하세요.

## 권장 사양
- 맥: Apple Silicon(M1 이상), macOS 13 이상, 저장공간 6GB
- 윈도우: 윈도우 10/11 64비트, 메모리 8GB 이상, 저장공간 5GB. NVIDIA 그래픽카드가 있으면 훨씬 빠릅니다.

## 설치할 때 경고가 뜨면
- 맥: 앱을 연 뒤 "열 수 없음"이 뜨면 시스템 설정 → 개인정보 보호 및 보안 → 맨 아래 "그래도 열기"
- 윈도우: "Windows의 PC 보호" 창에서 "추가 정보" → "실행"

## 주의
내가 참여한 대화의 녹음은 괜찮지만, 내가 빠진 다른 사람들의 대화를 몰래 녹음하면 통신비밀보호법 위반입니다.
