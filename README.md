# 모두의 회의록

회의를 녹음하면 **누가 무슨 말을 했는지 나눠서 텍스트(txt)** 로 정리해 주는 무료 프로그램입니다. 맥과 윈도우에서 쓸 수 있습니다.

- **완전 무료** — 광고, 회원가입, 사용 횟수 제한이 없습니다.
- **내 컴퓨터 안에서만 처리** — 녹음과 텍스트는 어디에도 전송되지 않습니다.
- **말한 사람별 정리** — `[00:01:23] [화자1] ...` 형식으로 시간과 함께 기록합니다.
- **내 목소리 등록** — 한 번 등록해 두면 내가 한 말은 `[나]`로 표시됩니다.
- **스마트폰 녹음도 OK** — 휴대폰으로 녹음한 m4a, mp3, wav 파일을 넣어도 됩니다.

## 다운로드

[**Releases**](../../releases/latest)에서 내 컴퓨터에 맞는 파일을 받으세요.

| 컴퓨터 | 파일 | 필요 사양 |
|---|---|---|
| 맥 | `ModuMeeting-mac.dmg` | Apple 실리콘(M1 이상), macOS 13 이상, 여유 공간 6GB (인텔 맥은 지원하지 않습니다) |
| 윈도우 | `ModuMeeting-windows-setup.exe` | 윈도우 10/11 64비트, 메모리 8GB 이상, 여유 공간 5GB |

처음 실행할 때 AI 모델(약 1.6~3GB)을 한 번만 내려받습니다. 이후에는 인터넷 없이도 동작합니다. 회사·학교 네트워크에서 huggingface.co 접속이 막혀 있으면 내려받기가 실패하니, 처음 한 번은 다른 네트워크에서 실행해 주세요.

## 설치

**맥**
1. `ModuMeeting-mac.dmg`를 열고 "모두의 회의록"을 응용 프로그램 폴더로 끌어 넣습니다.
2. 처음 열 때 "열 수 없음"이 뜨면 **시스템 설정 → 개인정보 보호 및 보안** 맨 아래 **"그래도 열기"** 를 누릅니다.
3. 마이크 사용 허용 창이 뜨면 "허용"을 누릅니다.

**윈도우**
1. `ModuMeeting-windows-setup.exe`를 실행합니다.
2. "Windows의 PC 보호" 창이 뜨면 **"추가 정보" → "실행"** 을 누릅니다.
3. "다음"을 눌러 설치를 마칩니다.

> 무료 배포라 앱 서명 비용을 쓰지 않아 처음 한 번 경고가 뜹니다. 소스 코드는 이 저장소에 모두 공개되어 있습니다.

## 사용 방법

1. **내 목소리 등록 (선택, 1번만)** — "내 목소리 등록"을 누르고 조용한 곳에서 20초 정도 평소처럼 말한 뒤 "등록 끝내기"를 누릅니다.
2. **녹음** — 참석자 수를 고르고(모르면 "자동") "녹음 시작"을 누릅니다. 회의가 끝나면 "녹음 정지"를 누르세요. 정지하는 즉시 텍스트로 만들기 시작합니다.
3. **녹음 파일로 만들기** — 이미 녹음한 파일은 "녹음 파일 선택해서 텍스트로 만들기"로 고릅니다. 여러 개를 골라도 차례로 처리합니다.
4. **결과 확인** — "결과 열기" 또는 "결과 폴더"를 누르면 `문서/모두의회의록` 폴더의 txt가 열립니다.
5. **용어집** — 회사 이름, 제품 이름을 쉼표로 적어 두면 더 정확하게 받아씁니다. `틀린말 => 바른말` 형식으로 적으면 자동으로 고쳐 줍니다.

결과 예시:
```
[00:01:23] [나] 다음 주까지 시안 두 개 준비하겠습니다.
[00:01:31] [화자1] 좋습니다. 예산은 지난번 금액 그대로 가죠.
[00:01:40] [화자2] (잘 안 들림) 일정은 3(?)일 정도 여유 있어요.
```

이 txt를 ChatGPT, Claude 같은 AI에 넣고 "회의 요약해 줘", "할 일 정리해 줘"라고 하면 회의록이 완성됩니다.

## 자주 묻는 질문

**(잘 안 들림), 숫자(?) 표시는 뭔가요?**
알아듣기 어려운 구간은 지어내지 않고 `(잘 안 들림)`으로, 확신이 낮은 숫자는 뒤에 `(?)`를 붙여 둡니다. 중요한 숫자는 그 시간대 녹음을 다시 들어 보세요.

**녹음했는데 소리가 안 들어가요.**
마이크 권한이 꺼져 있는 경우입니다. 윈도우는 **설정 → 개인 정보 및 보안 → 마이크**에서 "데스크톱 앱이 마이크에 액세스하도록 허용"을, 맥은 **시스템 설정 → 개인정보 보호 및 보안 → 마이크**에서 "모두의 회의록"을 켜 주세요. 녹음 화면에도 안내가 뜹니다.

**화자 수가 틀리게 나와요.**
참석자 수를 "자동" 대신 정확한 인원으로 골라 다시 처리하면 훨씬 정확해집니다.

**처리 시간은 얼마나 걸리나요?**
1시간 회의 기준 M 시리즈 맥 약 15분, NVIDIA 그래픽카드 PC 10~20분, 일반 노트북은 1시간 이상 걸릴 수 있습니다.

**NVIDIA 그래픽카드가 있으면?**
자동으로 감지해 가속 파일(약 1GB)을 한 번 내려받고 훨씬 빠르게 처리합니다.

## 주의

내가 참여한 대화를 녹음하는 것은 괜찮지만, 내가 빠진 다른 사람들의 대화를 몰래 녹음하면 **통신비밀보호법 위반**입니다. 녹음 파일과 회의 내용 관리에 유의해 주세요.

## 개발자용

```bash
# 맥
pip install -r requirements-mac.txt
# 윈도우
pip install torch torchaudio --index-url https://download.pytorch.org/whl/cpu
pip install -r requirements-win.txt

python app/main.py
```

설치 파일은 GitHub Actions(`.github/workflows/build.yml`)가 `v*` 태그를 올리면 자동으로 만들어 Releases에 올립니다.
